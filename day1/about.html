About QuickNotes

QuickNotes is a simple app for capturing short notes and ideas before you forget them. It keeps everything on one page so you can add and review notes in seconds.

How to use QuickNotes

  1. Type your note into the text box.
  2. Click the "Add Note" button.
  3. Read your saved notes in the "Your notes" list.

Features

  • Add a note in seconds
  • See all your notes in one list
  • Simple, distraction-free page

Keyboard shortcuts

Shortcut Action
Enter Add the note
Ctrl + Z Undo typing
